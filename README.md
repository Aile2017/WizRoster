# WizRoster

UCSD p-System 版 Wizardry #1 のキャラクタ編集ツール(Windows / C# WinForms / .NET 10)。
ディスクイメージの `SCENARIO.DATA` からキャラクタ 20 人分とマスタデータ(アイテム・呪文)を読み、編集して書き戻す。

## 使い方

```
dotnet run --project src/WizRoster -- <イメージのパス>
```

- ファイルはドラッグ&ドロップでも開ける。
- 上書き保存すると、元のファイルを `<名前>.bak_yyyyMMdd_HHmmss` に残してから書き込む。
- エミュレータがイメージを開いている間は保存しないこと。

## 対応イメージ

| 機種 | 形式 | 状態 |
|---|---|---|
| PC-98 | FDI(ヘッダ + シリンダ 0 を飛ばしたブロック) | 確認済み |
| Apple II | 140KB DOS 3.3 順 `.dsk`(シナリオディスク 2 枚目) | 読み込み確認済み |
| PC-DOS | 生イメージ(保存ディスク `SAVE1.DSK`) | 確認済み(名前は ASCII.KRN から) |
| MSX2 | 720KB 生イメージ(Game / User Disk。ボリュームはディスク後半の 368640 バイト目から) | 確認済み |
| PC-8801 | D88(1 ファイルに 2 枚。キャラクタのいるディスクを自動で選ぶ。ボリュームはシリンダ 0 を飛ばした位置から) | 確認済み |

D88 はセクタを「トラックの順 → セクタ番号 R の順」に並べ、256 バイトのセクタ 2 つを 1 ブロックとして読み書きする
(`D88Disk.cs`)。1 つのファイルに複数のディスクがあるときは「ファイル → ディスクの切り替え」で選べる。
書き込み禁止のディスク(マスターディスク)は開けるが、保存はしない。

形式の判別は `ImageLoader` が行う。候補は順に試し、`SCENARIO.DATA` の目次まで読めたものを使う
(MSX2 版の Game Disk には、ディスク前半に古いディレクトリの写しが残っているため)。
呪文名の表が壊れているとき(MSX2 版の User Disk は先頭の名前が 0Dh で上書きされている)は `ASCII.KRN` から読む。新しい形式は `IBlockImage`(512 バイトブロックの読み書き)を実装して候補に足す。

## データの位置の求め方

`SCENARIO.DATA` 先頭の目次(TSCNTOC)を使うので、機種ごとの固定オフセットは持たない。

| 位置 | 内容 |
|---|---|
| +0 | シナリオ名 STRING[40] |
| +42 | RECPER2B[8]: 1024 バイトあたりの件数 |
| +58 | RECPERDK[8]: 件数 |
| +90 | BLOFF[8]: 開始ブロック(4 = アイテム, 5 = キャラクタ) |

- キャラクタ i: `BLOFF[5]*512 + (i / 4) * 1024 + (i % 4) * 208`
- アイテム n: `BLOFF[4]*512 + (n / 13) * 1024 + (n % 13) * 78`
- 呪文名: 迷宮データ(`BLOFF[1]`)の 2 ブロック前が魔術師、1 ブロック前が僧侶。0Dh 区切りで、レベルの区切りに `*`。

キャラクタ(208 バイト)とアイテム(78 バイト)の項目は `Character.cs` と `ItemDef.cs` を参照。

### PC-DOS 版(アイテム表に名前がない版)

- 目次の `UNUSEDXX[8]`(+74)が 1 件のバイト数になっていて、アイテムは 46 バイト(78 バイトから名前の 32 バイトを除いたもの)。
- アイテム名と呪文名は、同じディスクのメッセージファイル `ASCII.KRN` から読む(`KrnMessageFile.cs`)。
  - 呪文: メッセージ 5001〜5050(`*` がレベルの区切り。レベル 7 の次の `*` から僧侶)
  - アイテム n: 14000+2n が未鑑定名、14000+2n+1 が名前
  - 名前の中の小文字は略記で、`w` = ` OF `、`x` = `POTION`、`y` = `SCROLL` と推測して展開する
- `ASCII.KRN` の暗号: `文字[i] = (暗号[i] − 23·(i+1) − 67·(番号 mod 51)) mod 256`

## 構成

- `src/WizRoster.Core`: イメージ・UCSD ディレクトリ・シナリオ・キャラクタの読み書き(GUI に依存しない)
- `src/WizRoster`: WinForms の画面
- `tests/WizRoster.Tests`: xUnit。実イメージがあればそれを使って確かめる(環境変数 `WIZROSTER_PC98` / `WIZROSTER_APPLE2` で場所を変えられる)
