# 05. ASCII.KRN(アスキー移植版のメッセージファイル)

PC-98・PC-DOS・MSX2・PC-8801 版(アスキーによる移植)は、ゲームの画面の文字列を `ASCII.KRN` にまとめて持つ。
ゲーム本体はメッセージ番号で文字列を引く。文字列は暗号化されていて、そのままでは読めない。
PC-98 版の `ASCII.KRN` には、シフト JIS の日本語のメッセージも入っている。

## 1. 構造

| 位置 | 内容 |
|---|---|
| +0 | 索引表の開始ブロック |
| +2 | 索引表のバイト数(1 件 1 ワード。値 × 2 がメッセージのバイト位置) |
| +4 | 範囲の木の開始ブロック |
| +6 | 範囲の木のバイト数(1 件 10 バイト) |
| +8〜 | メッセージ本体 |

- 範囲の木の 1 件: (開始番号, 終了番号, 索引の先頭, 左, 右) の 5 ワード。
  メッセージ番号 m(開始〜終了)は、索引の (先頭 + m − 開始番号) 番目。先頭の 1 件(0x8001, 0x8001, …)は見出し。
- メッセージ: 1 バイトの文字数に続いて本文(ワード境界に揃える)。

例: PC-DOS 版 #1 は、索引が 45 ブロック目から 1517 件、範囲の木が 51 ブロック目から 101 件。

## 2. 暗号

メッセージ番号を m、本文の i 文字目(0 から)の暗号のバイトを e[i] とすると、

```
文字[i] = (e[i] − 23 × (i + 1) − 67 × (m mod 51)) mod 256
```

PC-DOS 版 #1 では 1517 件中 1515 件が正しい文字列になった(残り 2 件は文字列ではないデータらしい)。

## 3. 主なメッセージ番号

| 番号 | 内容 |
|---|---|
| 1〜2031 付近 | 画面のメッセージ(例: 35 `THIS SCENARIO DISK IS EITHER NOT`、1040 `CAST WHICH SPELL ?`、1126 `SILENCED`) |
| 5000 | `NO SPELL` |
| 5001〜5050 | 呪文名(`*` がレベルの区切り。最初の名前にも付く。7 つ目の区切りの次の `*` から僧侶) |
| 10000〜10004 | 種族名(値 1〜5)。`NO RACE` はない |
| 10010〜10012 | 属性名(値 1〜3)。`UNALIGN` はない |
| 10020〜10025 | 能力値の名前(STRENGTH、I.Q.、PIETY、VITALITY、AGILITY、LUCK) |
| 10030〜10037 | 職業名(値 0〜7) |
| 10040〜10047 | 状態名(値 0〜7。`PARALYZED`、`PETRIFIED` のように略さない) |
| 13000 番台 | モンスターの名前 |
| 14000 + 2n | アイテム n の鑑定前の名前 |
| 14000 + 2n + 1 | アイテム n の名前 |

## 4. 名前の中の略記

アイテム名の中の小文字は略記らしい。展開は推測(ゲーム画面での表示とは突き合わせていない)。

| 略記 | 展開 | 例 |
|---|---|---|
| `w` | ` OF ` | `RINGwHEALING` → RING OF HEALING |
| `x` | `POTION` | `xwDIOS` → POTION OF DIOS |
| `y` | `SCROLL` | `ywKATINO` → SCROLL OF KATINO |

メッセージの中の `^`(名前などの差し込み)、`~`(キーの表示)、`l)EAVE` の `l` なども、表示のときに置き換えられる記号らしい。
