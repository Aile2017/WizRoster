# 03. キャラクタのレコード(208 バイト)

全機種・#1〜#3 で同じ形式。値はすべてリトルエンディアン。名前は Wizardry のソースの変数名(型 TCHAR)。

## 1. データ型

| 型 | 形式 |
|---|---|
| INTEGER | 16 ビットの符号付き整数(−32,768〜32,767)。32,768 以上を書くとゲームからは負の数に見える |
| BOOLEAN | 1 ワード。0 = 偽、0 以外 = 真(1 のことも 0xFFFF のこともある) |
| STRING[n] | 先頭 1 バイトが長さ、続けて文字。n + 1 バイト(偶数に切り上げ) |
| TWIZLONG | 3 ワード。各ワード 0〜9,999 の 10000 進数で、下位ワードが先頭。値 = w0 + w1 × 10,000 + w2 × 100,000,000(最大 999,999,999,999) |
| 5 ビット詰め | 1 ワードに 5 ビットの値を 3 つ詰める(下位から 0・1・2 番目)。ワードをまたがない |
| ビット列 | 要素 n はバイト n ÷ 8 のビット n mod 8 |

## 4. LOSTXYL(+200〜+206)

ソースでは場面によって使い分ける共用の領域(LOCATION / POISNAMT / AWARDS)。

| 位置 | パーティーにいるとき | 迷宮に置き去りのとき(キャンプからの中断・全滅) |
|---|---|---|
| +200 | 毒の量(POISNAMT)。0 = 毒なし。毒を受けると 1、ガス爆弾の罠で 1 ずつ増える。迷宮を 1 歩ごとに HP がこの値だけ減る。治療・死亡で 0 | 位置 X(−1 = 行方不明) |
| +202 | − | 位置 Y(−1 = 行方不明) |
| +204 | − | 階(0 以外なら置き去り。−1 = 行方不明) |
| +206 | 称号のビット(クリアの印。ステータス画面で `>` などの記号になる) | 同じ |

- 置き去りにすると +200〜+204 が位置で上書きされるので、毒は消える。救出すると +200〜+204 は 0 に戻る。
- 最初の調査メモにあった「死亡したキャラクターで +204 が 1」は、迷宮の 1 階で死んで置き去りになっていたためと考えられる(蘇生すると 0 に戻る)。

## 5. 空きスロットと新規作成

- 空きスロットは名前の長さが 0 のレコード。中身はゲームのテンプレート(`UNSETH` で始まる)が多い。
- ゲームでキャラクタを作ると、セービングスローは 5 つとも 16 で始まり、後でゲームが計算し直す。
