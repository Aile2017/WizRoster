# 07. 確かめたことと、分かっていないこと

## 1. ゲームで確かめたこと(最初の調査、PC-98 版・PC-DOS 版 #1)

ディスクのバイトを直接書き換えて、ゲーム(エミュレータ)で動作を確かめた。

| やったこと | 結果 |
|---|---|
| dup ディスクのキャラクタを起動ディスクに移した(PC-98 版) | キャラクタの範囲を同じ位置にコピーして成功(両ディスクのファイル配置が同じだった) |
| 魔術師に全 21 呪文を覚えさせた | 覚えている呪文のビット(+138)を立てて成功。全呪文が使えた |
| 僧侶に全 29 呪文を覚えさせた | 同上 |
| 呪文の回数を 9 にした | **効かなかった**。ゲームがレベルと覚えている呪文から計算し直す |
| 死亡したキャラクタを蘇生させた | 状態(+40)を 5 から 0 にし、HP を最大に戻して成功 |
| 消滅(LOST)したキャラクタを戻した | 状態を 7 から 0 にして成功。酒場の一覧に出た |
| PC-98 版の 7 人を PC-DOS 版 `SAVE1.DSK` に移した | レコードを書き込んで成功(形式が同じ) |

参考: PC-DOS 版の魔術師 Lv12 の呪文の回数は 9, 9, 8, 6, 4, 3, 0、僧侶 Lv13 は 9, 9, 9, 7, 6, 4, 1。
全レベル 9 回にするには、かなり高いレベルが必要。

## 2. WizRoster のテストで確かめたこと

`tests/WizRoster.Tests`(xUnit)。手元の実イメージがあれば、それを使う。

- 5 機種・#1〜#3 の全イメージ(21 個)を開け、機種とシナリオを正しく判別できる。
- 保存すると、変わるのはキャラクタのレコードの範囲だけ(PC-98・PC-DOS・MSX2・Apple II・PC-8801 の #1)。D88 は 2 枚目のディスクが変わらない。
- アイテム名・呪文名・経験値の表・種族などの名前を、各機種で正しく読める。
- `ASCII.KRN` の復号、略記の展開。
- セービングスローの計算式が実キャラクタの値と一致する。
- 経験値とレベルの関係が実キャラクタと一致する。

## 3. 分かっていないこと

| 項目 | 状況 |
|---|---|
| +130 最高レベル | レベル以上の値なのはデータで確認。ゲームでの使い道は不明 |
| +174・+180・+182 | 命中の補正・クリティカル・攻撃回数と推測 |
| +190〜+199 のビット列 | +196 が抵抗のビットなのはプログラムで確認。ほかは推測 |
| アイテムの SPECIAL・CHANGETO・HEALPTS など | 推測 |
| セービングスロー 3 番目 | 判定に使われていない(#1〜#3)。計算だけされる |
| #3 の持ち物の番号 +1000 | 1000 を引くと #3 のアイテムとして合う。足す意味は不明 |
| `ASCII.KRN` の略記(`w`・`x`・`y`) | 展開は推測 |
| 値を書き換えた後のゲームの動き | 書き換えた値(セービングスロー・AC・呪文の回数など)が、いつ計算し直されるかは追っていない |
| WizRoster で編集・保存したディスクのゲームでの動作 | まだ試していない |
| 置き去りのパーティーの再開 | 処理を追っていない |
| PC-DOS・MSX2・PC-8801 版のゲーム本体 | 逆アセンブルしていない(PC-98 と同じと考えている) |
| #4・#5 | 形式が違うので対象外 |
