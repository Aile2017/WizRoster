# 08. モンスター(ZENEMY)

`SCENARIO.DATA` の区分 2(ZENEMY)。位置の求め方はほかの区分と同じ([02-scenario-data.md](02-scenario-data.md))。
#1 は 101 件(Apple II・PC-98・PC-DOS で同じ)。1024 バイトに 6 件(名前なしの版は 10 件)。

## 1. レコード(TENEMY, 158 バイト)

名前のない版(PC-DOS 版など。アイテムが 46 バイトの版)は、先頭の名前 64 バイトがない 94 バイト。
名前は `ASCII.KRN` の 13000 + 4n から(+0 不確定名、+1 不確定名の複数形、+2 名前、+3 名前の複数形)。

## 2. 名前の表記

- アスキー移植版の `ASCII.KRN` では、WERDNA が `**W*E*R*D*N*A**`(Apple II・PC-98 の SCENARIO.DATA では `W E R D N A`)。そのまま出す。

## 3. 未解析のこと

- 経験値の計算(EXPAMT が 0 のとき)。
- 「推測」の項目をゲームのプログラム(CINIT・COMBAT・REWARDS など)で確かめること。
- 絵(PIC)の置き場所と形式。PC-98 版は `200.MONSTERS`・`400.MONSTERS`、Apple II 版は 1 枚目のディスクにあると思われる。
