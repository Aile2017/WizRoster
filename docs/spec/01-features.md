# 01. 画面と機能

## 1. 対応するディスク

| 機種 | イメージ | シナリオ |
|---|---|---|
| PC-98 | FDI | #1〜#3 |
| PC-DOS | 生イメージ(`WIZn.DSK`、`SAVEn.DSK`) | #1〜#3 |
| MSX2 | 720KB 生イメージ(Game Disk / User Disk) | #1〜#3 |
| Apple II | 140KB `.dsk`(DOS 3.3 順。シナリオディスク) | #1〜#3 |
| PC-8801 | D88(1 ファイルに複数のディスク) | #1〜#3 |

形式は中身で判別する(拡張子では決めない)。#4・#5 は対象外。

## 2. ファイルを開く・保存する

- 開き方: メニュー「ファイル → 開く」、ツールバーの「開く」、ウィンドウへのドラッグ&ドロップ、起動時の引数(`WizRoster.exe <イメージ>`)。
- 開くと、タイトルバーとステータスバーの左端に「PC-DOS 版 #2 ダイヤモンドの騎士」のように機種とシナリオを出す。
  ステータスバーには、イメージの形式、ボリューム名、シナリオ名、名前の取得元(アイテム名・呪文名・種族など)、ファイルの場所も出す。
- **上書き保存**: 元のファイルを `<名前>.bak_yyyyMMdd_HHmmss` にコピーしてから、一時ファイルに書いて置き換える。
  書き換えるのはキャラクタのレコードだけで、ほかのバイトは変えない。
- **名前を付けて保存**: 別のファイルに保存する(保存先が既にあればバックアップを残す)。
- 保存していない変更があるときは、別のファイルを開く・終了するときに確認する。
- 保存に失敗したとき(エミュレータがファイルを開いているなど)は、理由を表示する。

### 2.1 D88(複数のディスク)

- キャラクタの入っているディスクを自動で選ぶ。
- 「ファイル → ディスクの切り替え」に、各ディスクの名前、キャラクタの有無、書き込み禁止かどうかを出し、切り替えられる。
- 書き込み禁止のディスク(マスターディスク)は、開いて編集できるが保存はしない(保存しようとすると理由を表示し、「書き出し」を案内する)。
  タイトルとステータスバーに「[書き込み禁止]」と出す。

## 3. 画面の構成

- 上: メニュー(ファイル・キャラクタ・便利)とツールバー。
- 20 個のタブ(スロット 0〜19)。タブ名は「番号: 名前」、空きスロットは「(空き)」、変更したスロットには `*`。
- 空きスロットのタブは「このスロットにキャラクタを作る」「ファイルから読み込む」のボタンだけを出す。
- キャラクタのタブは、次の欄に分かれる。

| 欄 | 内容 |
|---|---|
| 基本 | 名前、パスワード、種族、職業、属性、状態、毒、年齢(週。歳と週の表示つき)、迷宮内、レベル・最高レベル、HP・最大 HP、AC、所持金、経験値 |
| 経験値の説明 | 「経験値は Lv ○ 相当 / Lv ○ まであと ○○」。「レベルに合わせる」ボタン |
| 能力値 | 力・知恵・信仰心・体力・素早さ・運 |
| セービングスロー | 毒・麻痺・即死 / 石化 / 未使用 / ブレス・ガス / 呪文・罠。項目にマウスを乗せると、用途・避ける条件・職業と種族の補正・計算式を出す |
| 持ち物 | 8 行の一覧表(アイテム、装備、呪い、鑑定)。「▲ 上へ」「▼ 下へ」で選んだ行を移動。下の詳細欄は、行を選んだときだけそのアイテムの情報を出す |
| 呪文 | 魔術師 21・僧侶 29 のチェックリスト、レベルごとの回数 |
| その他(生の値) | +174 以降の項目を生の数値で編集(16 進は `0x` を付けて入力) |
| 16 進 | 208 バイトの 16 進表示 |
| 警告 | ゲームのルールに合わない点(下の 5 章) |

- 種族・職業・状態・属性のコンボボックスの名前は、ディスクにあるものを使う(`ASCII.KRN` → 目次の名前 → 既定の日本語名の順)。
- アイテムと呪文の一覧も、開いたディスクから読む。#3 の「1000 + 番号」の持ち物は「028 SALLET (+1000)」のように出し、番号はそのまま残す。
- 持ち物は、途中の行を「(なし)」にすると後ろが前に詰まる(ゲームは先頭から「持ち物の数」だけを読むため)。
- 持ち物や装備を変えても、装備から計算する値(AC、命中、攻撃回数、ダメージ、セービングスローなど。「その他」の +174〜+198)は計算し直さない。ゲームで装備し直すと計算し直される([06-game-program.md](../analysis/06-game-program.md) 3.5)。
- 毒の欄は、迷宮に置き去り中(+204 が 0 以外。+200〜+204 が位置になっている)は編集できない。

## 4. 操作

| メニュー | 操作 |
|---|---|
| キャラクタ → 別のスロットへコピー | 選んでいるキャラクタを別のスロットに複製(上書きは確認) |
| キャラクタ → 別のスロットと入れ替え | 2 つのスロットを入れ替える |
| キャラクタ → 書き出し / 読み込み | 1 人分をファイルに保存する・ファイルから読み込む(6 章) |
| キャラクタ → 新規作成 | レベル 1 の人間の戦士(名前 `NEW番号`)を作る |
| キャラクタ → 削除して空きにする | 開いたディスクの空きスロットの内容で上書きする |
| キャラクタ → このスロットの変更を取り消す | 最後に保存(読み込み)した内容に戻す |
| 便利 → 魔術師 / 僧侶の呪文をすべて覚える | 覚えている呪文のビットを立て、その系統の回数をゲームと同じ計算(職業とレベルから。[06-game-program.md](../analysis/06-game-program.md) 3.3)で入れる |
| 便利 → 呪文をすべて忘れる | ビットをすべて消す |
| 便利 → 経験値をレベルに合わせる | 経験値を今のレベルに必要な最小の値にする |
| 便利 → HP を全回復 | HP を最大 HP にする |
| 便利 → 状態を正常にする | 状態を正常にし、HP が 0 以下なら最大にし、毒を消す(置き去り中は位置を守るため毒は触らない) |
| 便利 → 持ち物をすべて鑑定し、呪いを解く | 鑑定済みにし、呪いを外す |
| 表示 → アイテム一覧(F7) / モンスター一覧(F8) | ディスクから読んだアイテム表・モンスター表を一覧で見る(読み取り専用)。列の見出しで並べ替え、行を選ぶと下にすべての項目。モンスターは絵も出す(今は PC-98・PC-8801 版だけ)。開いたまま編集を続けられ、別のイメージを開くと閉じる |
| 便利 → ボルタック商店の在庫 | アイテムごとの在庫数(−1 = 無限、0 = 並ばない)の一覧を編集する。店に並ぶか(呪われた品は並ばない)も出す。保存でアイテム表の在庫の 2 バイトだけを書く |

## 5. 入力の範囲と警告

### 5.1 入力の範囲

| 項目 | 範囲 |
|---|---|
| レベル、最高レベル、HP、最大 HP、年齢、毒 | 0〜32,767 |
| AC | −32,768〜32,767 |
| 所持金、経験値 | 0〜999,999,999,999 |
| 能力値、セービングスロー | 0〜31 |
| 呪文の回数 | 0〜9 |
| 名前、パスワード | 15 文字までの ASCII(空白〜`~`) |
| その他(生の値) | 符号付きの項目は −32,768〜32,767、ビット列は 0〜65,535 |

ディスクにもともと範囲外の値があるときは、画面では端の値に丸めて表示し、警告で実際の値を知らせる(触らなければ元の値のまま保存する)。

### 5.2 警告(ゲームのルールに合わない点)

入力は止めず、警告欄に出すだけ。

- 種族・職業・状態・属性の値がゲームの範囲外
- データとして範囲外の値(レベルなどが 32,768 以上、所持金・経験値の 1 ワードが 9,999 を超える)
- 能力値が 18 を超える
- 職業の条件(能力値・属性)を満たしていない。条件は一般的な Wizardry の知識による(戦士: 力 11、魔術師: 知恵 11、僧侶: 信仰心 11・善か悪、
  盗賊: 素早さ 11・中立か悪、司教: 知恵 12・信仰心 12・善か悪、侍: 力 15・知恵 11・信仰心 10・体力 14・素早さ 10・善か中立、
  君主: 力 15・知恵 12・信仰心 12・体力 15・素早さ 14・運 15・善、忍者: すべて 17・悪)
- HP が最大 HP を超える、レベルが最高レベルを超える、死亡以上なのに HP が残っている
- レベルに対して経験値が足りない(経験値が多いのは宿屋でまだ上がっていないだけなので警告しない)
- 持ち物: 数が 0〜8 の範囲外、アイテム表にない番号、装備できない職業、属性違いの装備、同じ部位を 2 つ以上装備、装備品でないものを装備
- 呪文: 未使用のビット 0 や表にない番号が立っている、回数が 9 を超える

## 6. 書き出し・読み込みの形式

| 形式 | 内容 |
|---|---|
| `.wchr` | 208 バイトの生データ。そのまま復元できる |
| `.json` | 人が読める形式。`Raw`(208 バイトの 16 進)を土台にし、各項目の値で上書きして読み込む |

JSON の項目: `Name`、`Password`、`InMaze`、`Race`・`Class`・`Status`・`Alignment`(と名前)、`Age`、`Attributes`[6]、`SavingThrows`[5]、
`Gold`、`Experience`、`Level`、`MaxLevel`、`Hp`、`HpMax`、`ArmorClass`、`Items`(各要素に `Index`、`Name`、`Equipped`、`Cursed`、`Identified`)、
`Spells`(ビット番号)、`SpellNames`、`MageSpellPoints`[7]、`PriestSpellPoints`[7]、`Extra`(`"+174"` などの位置と値)、`Raw`。

- 読み込むときは、5.1 章と同じ範囲で確かめ、範囲外があればすべて並べてエラーにする。
- `Extra` は「その他」に出している位置だけを受け付ける(名前などほかの位置は書き換えさせない)。
- 範囲外の値を持つキャラクタは JSON では読み戻せないので、`.wchr` で移す。
- 機種をまたいで移せる(レコードの形式とアイテムの番号が同じ)。シナリオをまたぐとアイテムの番号の意味が変わるので注意。
